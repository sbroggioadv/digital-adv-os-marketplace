# Digital Adv OS — Contencioso, Administrativo e LGPD

Marketplace do plugin **digital-adv-os** (versão 0.3.0), da Sbroggio Advocacia & IA Combativa. Apoio ao advogado de qualquer polo em caso digital, na fase administrativa (ANPD, Anatel, Ministério Público, domínio `.br`), na fase judicial completa e na LGPD consultiva. Escopo e limites no [README do plugin](digital-adv-os/README.md).

Produto vendido sob licença de uso: o código está em repositório público para viabilizar a instalação, mas não é software livre. Condições em [LICENCA](LICENCA).

## Instalação

- **Claude Desktop (Cowork):** Personalização → Plugins → Adicionar → Adicionar marketplace → Adicionar de um repositório → `https://github.com/sbroggioadv/digital-adv-os-marketplace` → Sincronizar; depois instale **digital-adv-os**.
- **Claude Code:** `claude plugin marketplace add sbroggioadv/digital-adv-os-marketplace` e `claude plugin install digital-adv-os@digital-adv-os-marketplace`.

Depois de instalar, rode `/digital-adv-install` e conduza o caso por `/digital-adv-master`. Toda entrega é minuta para revisão do advogado.
